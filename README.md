# LouisFlutterDemo

| 项目 | 功能 |
|------|------|
| `my_flutter_app` | 基础 app 结构（app/core/features 分层）+ Provider 状态管理，登录流程示例 |
| `my_flutter_cs` | Clean Architecture 分层实践（data/domain/ui），auth 模块示例 |
| `my_flutter_db` | 在 Clean Architecture 基础上加本地数据库（Drift），含 DAO 与本地数据源 |
| `my_flutter_dio` | Dio 网络请求入门：ApiClient 封装、登录接口、错误映射 |
| `my_json_serializable` | json_serializable JSON 序列化示例 |
| `my_flutter_gen` | 代码生成综合实践：freezed + json_serializable + build_runner |
| `my_riverpod` | Riverpod 状态管理，含 riverpod_annotation 注解式写法 |
| `my_video_player` | 视频播放：video_player + chewie，含 HLS 流播放 |
| `my_draggable_scrollable_sheet` | DraggableScrollableSheet 可拖拽底部面板 + 仪表盘页面 |
| `my_flutter_module` | Flutter Module（Add-to-Android）基础模板 |
| `my_flutter_project` | Android 原生 App + flutter_module 混合开发示例 |
